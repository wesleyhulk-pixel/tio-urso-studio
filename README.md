# Tio Urso Studio — Alpha 0.2

Atualização de testes no Android. Não é versão comercial.

## Novidades

- 28 opções de fontes (21 estilos criativos online + 7 locais).
- Importar fonte pessoal TTF/OTF; ao salvar projeto em JSON, a fonte importada acompanha o projeto.
- Exportação **NORMAL** ou **ESPELHADA**, selecionada explicitamente.
- Prévia de como ficará a orientação do arquivo, tanto para PNG quanto PDF.
- Nome dos arquivos identifica `normal` ou `espelhada`.
- Fontes online precisam de conexão para carregar na primeira utilização.

## Atualizar GitHub Pages

Faça backup do projeto usando **Salvar projeto** antes de atualizar. Substitua `index.html`, `app.js` e `style.css` na raiz do repositório `tio-urso-studio`. Aguarde o deploy e atualize a página no Chrome.

**Observação:** o espelhamento é necessário em alguns processos de sublimação, mas há drivers que fazem isso automaticamente. Evite espelhar duas vezes. Verifique a orientação da sua impressora antes de transferir.

**Compatibilidade:** esta versão permanece um protótipo; impressão, 300 DPI, ICC e tamanho físico precisam ser testados em equipamentos reais.
