# Tio Urso Studio — Alpha 0.8.4

## Correção da versão (importante)
No pacote 0.8.3, o README estava certo, mas o `index.html` ainda mostrava 0.8.2 e carregava JS/CSS com `?v=0820`. Por isso as alterações podiam não aparecer.

Agora o HTML, o título, a etiqueta visual e o rodapé indicam **0.8.4**, com `mock3d.js?v=0840` e `app.js?v=0840`.

## Ajuste: caneca de chopp de vidro jateado
- Corpo 3D **mais estreito** (a geometria da caneca e da alça é reduzida proporcionalmente no diâmetro).
- **Vidro jateado menos transparente**, com opacidade maior que na Alpha 0.8.2.
- Área da arte corrigida para acompanhar o diâmetro mais estreito (sem o bug da máscara invisível).
- Faixa frontal de impressão ligeiramente mais contida.

## Preservados
- **Caneca tradicional aprovada**: sem alterações de geometria ou comportamento.
- **Squeeze aprovado**: sem alterações de geometria, tampa ou estampa.

## Atualização pelo GitHub
1. Extraia o ZIP no celular ou computador.
2. No repositório do GitHub, envie **todos** os arquivos para a **raiz da branch `main`**, substituindo os anteriores (não crie outra pasta).
3. Confirme na lista do GitHub que o arquivo `index.html` foi atualizado, e não somente o README.
4. Aguarde o GitHub Pages concluir a publicação.
5. Abra `https://wesleyhulk-pixel.github.io/tio-urso-studio/?v=0840` e confira o selo **ALPHA 0.8.4**.

*Confira também a caneca de chopp no celular antes de considerar esse ajuste aprovado.*
