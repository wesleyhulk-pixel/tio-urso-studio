# Tio Urso Studio — Alpha 0.9.9 — Giro livre + zoom por pinça

Pacote completo para publicar na raiz do repositório GitHub Pages.

## Novidades da 0.9.9
- **1 dedo sobre o mockup:** gire o produto 3D para ambos os lados, dando quantas voltas desejar. O movimento não para em ±180°.
- **2 dedos sobre o mockup:** junte ou afaste os dedos para reduzir ou ampliar a visualização (70% a 300%).
- **Mouse:** arrastar para girar. A roda ajusta o zoom.
- **Atalhos:** botões de frente, lados, trás; controle de rotação; zoom +/−, slider e Centralizar continuam disponíveis.
- A pinça também funciona na prévia 2D quando WebGL não estiver disponível. Produtos planos aceitam zoom, mas não rotação 3D.
- Zoom do mockup também é aplicado na exportação PNG em retrato, como antes.

## Preservado da 0.9.8
- Modelo Meshy 3D, gola curva, mangas em cores sólidas e independentes.
- Seletor de cores avançado para Android/PC, tintas, textos, efeitos e acabamentos.
- Produtos, ajustes de estampa, impressão, prévias e demais funções.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Substitua os arquivos da raiz do repositório pelos 13 arquivos extraídos.
3. Faça o commit e atualize a página após a publicação.
4. Confira **Alpha 0.9.9** no topo.

A versão Alpha 0.9.8 permanece intacta no ZIP original.
