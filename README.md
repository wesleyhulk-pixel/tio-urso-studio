# Tio Urso Studio — Atualização leve GIF 360 mais lento

Esta atualização altera apenas o `app.js`.

## O que mudou
- Exportação do GIF 360 mais lenta e mais suave.
- Quantidade de quadros aumentada de **16** para **24**.
- Delay por quadro aumentado de **125 ms** para **150 ms**.
- Duração aproximada da volta completa: **3,6 segundos**.

## Como aplicar
Substitua o arquivo `app.js` do projeto atual por este arquivo.
